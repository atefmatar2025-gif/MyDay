# يومي – MyDay

تطبيق Android عربي بالكامل لإدارة المهام اليومية مع **منبه صوتي حقيقي** يرن في الوقت المحدد حتى والتطبيق مغلق، وبعد إعادة تشغيل الهاتف.

- Kotlin + Jetpack Compose + Material 3 (نهاري/ليلي، RTL كامل)
- Room لتخزين المهام محلياً، DataStore للإعدادات، يعمل دون إنترنت ودون إعلانات
- يدعم Android 8.0 (API 26) حتى Android 15 (API 35)

---

## 1. بناء ملف APK

### الطريقة (أ): GitHub Actions — دون Android Studio (تعمل حتى من الهاتف)
1. أنشئ مستودعاً جديداً على GitHub وارفع إليه **محتوى** مجلد `MyDay` كما هو (يجب أن يكون `settings.gradle.kts` و`.github/` في جذر المستودع).
2. يبدأ البناء تلقائياً. افتح تبويب **Actions** ← آخر تشغيل باسم *Build MyDay APK*.
3. بعد نجاحه (≈ 6–10 دقائق) نزّل الملف المضغوط **MyDay-builds** من أسفل الصفحة؛ بداخله:
   - `MyDay-debug.apk` — نسخة Debug (اسم الحزمة `com.myday.app.debug`)
   - `MyDay-release.apk` — نسخة Release مصغّرة ومحسّنة (موصى بها للاستخدام اليومي)
   - `MyDay-release.aab` — للرفع على Google Play
4. ثبّت الـ APK على الهاتف (اسمح بـ «التثبيت من مصادر غير معروفة» عند الطلب).

### الطريقة (ب): Android Studio
1. افتح المجلد `MyDay` عبر **File ▸ Open** (إصدار Ladybug أو أحدث، JDK 17).
2. انتظر مزامنة Gradle، ثم **Build ▸ Build App Bundle(s) / APK(s) ▸ Build APK(s)**.
3. أو شغّل مباشرة على الهاتف بزر ▶ بعد تفعيل «تصحيح USB».

### الطريقة (ج): سطر الأوامر
```bash
cd MyDay
./gradlew testDebugUnitTest          # اختبارات منطق المنبه والتكرار
./gradlew assembleDebug              # app/build/outputs/apk/debug/
./gradlew assembleRelease            # app/build/outputs/apk/release/
./gradlew bundleRelease              # app/build/outputs/bundle/release/ (AAB)
```
يتطلب JDK 17 وAndroid SDK 35 (متغير `ANDROID_HOME` أو ملف `local.properties`).

### التوقيع
- المشروع يحوي مفتاح Debug ثابتاً (`app/debug.keystore`) حتى تُثبَّت كل نسخة جديدة **فوق** السابقة دون حذف التطبيق — فلا تضيع المهام عند التحديث.
- نسخة Release تُوقَّع بهذا المفتاح افتراضياً. للنشر على Google Play أنشئ مفتاحك الخاص وأضفه كأسرار في المستودع:
  `MYDAY_KEYSTORE_BASE64` و`MYDAY_KEYSTORE_PASSWORD` و`MYDAY_KEY_ALIAS` و`MYDAY_KEY_PASSWORD`.
  ⚠️ تغيير مفتاح التوقيع يستلزم حذف النسخة القديمة؛ صدّر نسخة احتياطية من الإعدادات أولاً.

## 2. الصلاحيات المطلوبة (ولماذا)

| الصلاحية | السبب | كيف تُمنح |
|---|---|---|
| `POST_NOTIFICATIONS` | عرض المنبه وأزرار الإيقاف/الغفوة والتذكيرات (Android 13+) | حوار عند أول تشغيل |
| `SCHEDULE_EXACT_ALARM` | الرنين في الدقيقة المحددة بالضبط (Android 12+) | من شاشة الترحيب ← إعدادات النظام |
| `USE_FULL_SCREEN_INTENT` | إظهار شاشة المنبه فوق شاشة القفل (Android 14+ قد تتطلب موافقة) | من شاشة الترحيب |
| `RECEIVE_BOOT_COMPLETED` | إعادة جدولة المنبهات بعد إعادة تشغيل الهاتف | تلقائية |
| `FOREGROUND_SERVICE` + `FOREGROUND_SERVICE_MEDIA_PLAYBACK` | خدمة تشغّل صوت المنبه طوال مدة الرنين | تلقائية |
| `WAKE_LOCK` | إبقاء المعالج يعمل أثناء الرنين فقط | تلقائية |
| `VIBRATE` | الاهتزاز مع المنبه | تلقائية |

**لا يطلب التطبيق**: الإنترنت، الموقع، جهات الاتصال، ولا صلاحية قراءة التخزين — اختيار ملف صوتي أو حفظ النسخة الاحتياطية يتم عبر منتقي ملفات النظام.

استثناء البطارية **اختياري** ويُفتح من شاشة الصلاحيات (مفيد في هواتف Xiaomi/Huawei/Oppo/Vivo).

## 3. كيف تختبر المنبهات

> اختبر على هاتف حقيقي (المحاكي لا يمثّل سلوك البطارية الفعلي).

1. **الاختبار السريع**: الإعدادات ◂ «تجربة المنبه بعد دقيقة». أغلق التطبيق من قائمة التطبيقات الحديثة واقفل الشاشة. بعد دقيقة: تضيء الشاشة، تظهر شاشة المنبه، ويرن الصوت مع الاهتزاز.
2. **الأزرار**: جرّب «إيقاف المنبه»، «غفوة 5/10/15 د» (سيرن مجدداً بعد المدة)، و«إيقاف وتحديد المهمة كمنجزة». الأزرار نفسها موجودة في الإشعار.
3. **عدم الاستجابة**: اترك المنبه يرن حتى تنتهي مدته؛ سيعيد الرنين بعد الفاصل المحدد (افتراضياً 5 دقائق، حتى 3 مرات) ثم يعرض إشعار «فاتك منبه».
4. **إعادة التشغيل**: أنشئ مهمة بعد 5 دقائق ← أعد تشغيل الهاتف ← افتح القفل وانتظر. يرن في موعده (تعيد `BootReceiver` جدولة كل المنبهات).
5. **التذكير المسبق**: مهمة بعد 20 دقيقة مع «قبل 15 دقيقة» ← يصل إشعار تذكير بعد 5 دقائق، ثم المنبه الكامل في الموعد.
6. **التكرار**: مهمة يومية ← بعد رنينها تأكد من «تفاصيل المهمة ◂ المنبه: سيرن غداً…».
7. **تغيير الوقت/المنطقة الزمنية**: غيّر الساعة يدوياً من إعدادات الهاتف؛ تُعاد الجدولة تلقائياً.
8. **وضع عدم الإزعاج والوضع الصامت**: الصوت يُشغَّل على مسار **المنبه** (`USAGE_ALARM`) لذا يتبع مستوى صوت المنبه في الهاتف لا مستوى الرنين.

عبر ADB (اختياري):
```bash
adb shell dumpsys alarm | grep -A3 com.myday.app      # رؤية المنبهات المجدولة
adb shell cmd deviceidle force-idle                    # محاكاة وضع Doze ثم انتظار المنبه
adb shell am broadcast -a android.intent.action.BOOT_COMPLETED -p com.myday.app   # محاكاة الإقلاع
```

## 4. البنية التقنية وأسباب الاختيار

```
app/src/main/java/com/myday/app/
├── MyDayApp.kt / MainActivity.kt      حاوية الاعتمادات + شاشة البداية (SplashScreen API)
├── data/        Room: المهام، التصنيفات، سجل الإنجاز + المستودع (كل تعديل يُحفظ فوراً)
├── alarm/       AlarmScheduler · AlarmReceiver · AlarmService · AlarmActivity
│                BootReceiver · AlarmActionReceiver · AlarmSyncWorker · NotificationHelper
├── settings/    DataStore للإعدادات
├── backup/      تصدير/استعادة JSON
├── util/        حسابات التكرار، التنسيق والتاريخ الهجري، العبارات اليومية، الأصوات
└── ui/          Compose: الرئيسية، المهام، المحرر، التفاصيل، التقويم، الإحصائيات،
                 التصنيفات، الإعدادات، الصلاحيات + السمة والتنقل
```

| التقنية | لماذا |
|---|---|
| **`AlarmManager.setAlarmClock()`** | أدق نوع منبه في Android؛ يتجاوز وضع Doze ويظهر رمز المنبه في شريط الحالة. عند رفض صلاحية الدقة يُستخدم `setAndAllowWhileIdle` تلقائياً. |
| **خدمة أمامية + `MediaPlayer` (USAGE_ALARM)** | تحكم كامل بمدة الرنين والتكرار ورفع الصوت التدريجي — لا يمكن تحقيق ذلك بإشعار عادي. |
| **Full-screen intent + `AlarmActivity`** | شاشة منبه فوق القفل تشغّل الشاشة. |
| **PendingIntent فريد لكل (مهمة، نوع)** | يمنع تكرار المنبه للمهمة نفسها؛ أي إعادة جدولة تستبدل السابق. |
| **BootReceiver** | يعيد الجدولة بعد الإقلاع، تغيير الوقت/المنطقة، تحديث التطبيق، وتغيير صلاحية المنبه الدقيق. |
| **WorkManager (كل 12 ساعة)** | شبكة أمان منخفضة الاستهلاك تتأكد من بقاء المنبهات مجدولة — ليست للتوقيت الدقيق. |
| **Room بدون migrations هدّامة** | البيانات لا تُمحى أبداً عند التحديث. |
| **إشعار احتياطي بصوت منبه** | إذا منع النظام بدء الخدمة (حالات نادرة) يظهر إشعار بقناة صوت المنبه بدلاً من الصمت. |

**المهام المتكررة**: صف واحد لكل مهمة يحمل موعد التكرار القادم؛ عند الإنجاز يُسجَّل في جدول `completions` (لحساب الإحصائيات بدقة) وينتقل الموعد للتكرار التالي. التكرار يحترم التوقيت الصيفي (نفس الساعة المحلية).

## 5. ملاحظات صريحة

- **لم يُبنَ المشروع داخل بيئة التطوير التي أُنشئ فيها** لأنها تمنع تنزيل Android SDK ومكتبات Google. كُتب الكود بعناية وفُحص بنيوياً، لكن أول بناء على GitHub Actions أو Android Studio هو أول تجميع فعلي؛ إن ظهر خطأ تجميع أرسل رسالته وسيُصلَح.
- الخط: يُستخدم خط النظام العربي (Noto Sans Arabic على أغلب الأجهزة) لأنه واضح ولا يزيد حجم التطبيق. لإضافة خط مثل Cairo ضع ملفات `ttf` في `res/font` وعدّل `ui/theme/Theme.kt`.
- بعض الشركات (Xiaomi MIUI/HyperOS، Huawei EMUI) توقف التطبيقات بقوة؛ فعّل «التشغيل التلقائي» واستثناء البطارية للتطبيق إن لاحظت تأخراً.
