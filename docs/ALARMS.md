# كيف تعمل التنبيهات

## المسار الكامل لتنبيه واحد

1. **الحفظ**: `TaskInteractor.save()` ← `ReminderScheduler.rescheduleTask(taskId)`.
2. **الحساب** (`core/time/AlarmPlanner`): الموعد = (البداية أو الموعد النهائي) − الإزاحة، محوّلاً من الساعة المحلية إلى لحظة زمنية بالمنطقة الحالية. للمهام المتكررة يُختار أول موعد قادم. التنبيهات المتطابقة لنفس المهمة تُدمج (منع التكرار).
3. **التسجيل** (`AlarmScheduler`): كل تنبيه يملك خانة `PendingIntent` واحدة رقمها = معرّف التنبيه، فإعادة التسجيل **تستبدل** ولا تضيف.
   - صلاحية دقيقة + نمط «منبّه» ← `setAlarmClock()` (يظهر رمز المنبّه في شريط الحالة ومعفى من Doze).
   - صلاحية دقيقة + نمط «إشعار» ← `setExactAndAllowWhileIdle()`.
   - بلا صلاحية ← `setAndAllowWhileIdle()` (تقريبي).
4. **الإطلاق** (`AlarmReceiver`): يتحقق أن المهمة ما زالت موجودة ومفتوحة والتنبيه مفعّل، ويتجاهل أي **تسليم مكرر** لنفس الموعد (عبر `alarm_log`)، ثم يسجّل الموعد التالي للمهام المتكررة.
5. **الرنين** (`AlarmRingingService`): خدمة أمامية قصيرة تشغّل النغمة (`USAGE_ALARM`) بالمستوى المختار نسبةً إلى صوت المنبّه في النظام، مع نمط الاهتزاز، وإشعار بفئة `CATEGORY_ALARM` و`fullScreenIntent` إلى `AlarmActivity` (عند السماح).
6. **الاستجابة**: إيقاف / تأجيل 5–10–15–30 دقيقة / فتح المهمة — من الشاشة أو من أزرار الإشعار.
7. **عدم الاستجابة**: بعد «مدة الرنين» يتوقف الصوت ويُعاد التنبيه بعد «الفاصل» حتى «عدد التكرارات»، ثم يُسجَّل «لم يُستجب له».

## الحالات الخاصة

| الحالة | المعالجة |
|---|---|
| إعادة تشغيل الهاتف | `SystemEventsReceiver` (`BOOT_COMPLETED`, `QUICKBOOT_POWERON`) ← `rescheduleAll()` |
| تحديث التطبيق | `MY_PACKAGE_REPLACED` ← `rescheduleAll()` |
| تغيير الساعة/التاريخ يدوياً | `TIME_SET`, `DATE_CHANGED` ← `rescheduleAll()` |
| تغيير المنطقة الزمنية | `TIMEZONE_CHANGED` ← إعادة التحويل: مهمة 8:00 ترنّ 8:00 بالتوقيت الجديد |
| التوقيت الصيفي | وقت داخل «القفزة» (مثل 02:30 غير الموجودة) يُنقل للأمام بطول القفزة؛ وقت مكرر عند «الرجوع» يرنّ مرة واحدة بالإزاحة الأولى. مُختبر في `RecurrenceAndAlarmTest` |
| منح/سحب صلاحية المنبّهات الدقيقة | `SCHEDULE_EXACT_ALARM_PERMISSION_STATE_CHANGED` + عند العودة لصفحة الصلاحيات ← `rescheduleAll()` |
| تعديل وقت المهمة | إلغاء القديم ثم تسجيل الجديد في نفس الخانة |
| حذف تنبيه أو مهمة | إلغاء `PendingIntent` **قبل** حذف الصفوف |
| إكمال/إلغاء/أرشفة | لا يُسجَّل أي تنبيه لمهمة مغلقة أو مؤرشفة |
| شركات تُسقط المنبّهات | `MaintenanceWorker` كل 6 ساعات يعيد التسجيل (عملية idempotent) |
| منبّه ثانٍ أثناء رنين الأول | الأول يُحتسب «بلا استجابة» (ويتكرر لاحقاً) ويرنّ الثاني |

## سجل التنبيهات
كل حدث يُحفظ في `alarm_log` (جُدول / تقريبي / رنّ / أُوقف / أُجّل / بلا استجابة / أُعيد / أُلغي / تُجوهل كتكرار) ويُعرض في «الإعدادات ▸ سجل التنبيهات». يُحتفظ بـ 90 يوماً.

## قائمة اختبار يدوي على جهاز حقيقي
1. أنشئ مهمة بعد دقيقتين بتنبيه «في الموعد» نمط «منبّه» ← أقفل الشاشة ← يجب أن تظهر شاشة المنبّه مع الصوت.
2. اضغط «تأجيل 5 د» ← يرنّ بعد 5 دقائق.
3. اترك المنبّه دون استجابة ← يتوقف بعد مدة الرنين ويعود بعد الفاصل.
4. أنشئ مهمة بعد 5 دقائق ← أعد تشغيل الهاتف ← يجب أن يرنّ في موعده.
5. غيّر المنطقة الزمنية من إعدادات النظام ← افتح تفاصيل المهمة ← «التنبيه القادم» بنفس الساعة المحلية.
6. اسحب صلاحية المنبّهات الدقيقة ← صفحة الصلاحيات تُظهر التحذير ← التنبيه يصل كإشعار (قد يتأخر).
7. احذف مهمة لها تنبيه قبل موعدها ← يجب ألا يرنّ شيء (راجع سجل التنبيهات: «أُلغي»).
8. فعّل «عدم الإزعاج» ← سلوك المنبّه يتبع إعدادات «المنبّهات» في وضع عدم الإزعاج للنظام.
9. Xiaomi/Huawei/Samsung: إن تأخر التنبيه، استثنِ التطبيق من تحسين البطارية (صفحة الصلاحيات).
